MCP 2024-11-05 WAC / ACP 2.0 Zero-PII

AI 에이전트는 포드 전체 스토리지에 직접 접근할 수 없습니다. 모든 MCP 요청은 PolicyEngine::evaluate를 통과해 위임된 스코프(read, write, admin)를 검증받으며, 인가된 트리플만 직렬화되어 반환됩니다. 

// crates/wolin-mcp/src/server.rs — Scoped Agent Projection
impl McpAgentServer {
    pub async fn handle_tool_call(
        principal: &Principal,
        call: McpToolCall,
    ) -> Result<McpToolResult> {
        match call.name.as_str() {
            "wolin_query_semantic" => {
                let uri = ResourceUri("wolin://pod/semantic".into());
                let mode = AccessMode::Read;
                match PolicyEngine::evaluate(principal, &uri, mode) {
                    AccessDecision::Permit => project_subgraph(&call),
                    AccessDecision::Deny { reason } => deny(reason),
                }
            }
            other => deny(format!("Unknown tool: {other}")),
        }
    }
}
